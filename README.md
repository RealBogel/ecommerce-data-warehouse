# E-Commerce Data Warehouse

An end-to-end data engineering and analytics project using real-world
e-commerce data.

## Project Overview

This project builds a PostgreSQL data warehouse from raw e-commerce data
using Python for data ingestion and transformation and SQL for analytics.

## Tech Stack

- Python
- pandas
- PostgreSQL
- SQL
- Power BI / Tableau

## Project Structure

- `data/` - Raw source data
- `etl/` - Python ETL pipeline
- `sql/` - Database schemas, transformations, and analytics
- `docs/` - Architecture and data model documentation
- `dashboard/` - Dashboard files and screenshots
